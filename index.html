SIL COMPETITION

About RAIL-URJA

Problem

Railway movement creates vibrations. Our model explores whether part of that mechanical energy can be converted into useful electrical energy.

Solution

Piezoelectric plates generate electrical charge under mechanical stress. The output needs conditioning and safe storage.

Smart monitoring

The ESP32 reads compatible sensors and provides data over Wi-Fi to the VibeVolt dashboard.

Possible applications

After testing, harvested energy may support small low-power demonstrations or sensing circuits. Actual output depends on measured results.

How it works

  1. Train movement creates pressure or vibration.
  2. Piezoelectric plates generate an electrical signal.
  3. A suitable rectifier and energy-harvesting circuit condition the signal.
  4. A suitable storage circuit stores the energy safely.
  5. The ESP32 sends sensor readings to VibeVolt over Wi-Fi.

HARDWARE GUIDE

Connections & wiring

The following GPIO assignments are examples, not confirmed existing wiring. Verify the actual module pin labels before connecting power.

Safety: Never connect a piezo disc directly to an ESP32 GPIO. Never feed 5 V directly into an ESP32 GPIO input.

Provisional pin map

Power and ground

  • Use the supply voltage specified for each sensor module.
  • Connect grounds together where required by the sensor circuit's design.
  • GPIO 34 and 35 are input-only pins on the ESP32.
  • The ACS712 measures current only. A separate suitable voltage measurement circuit is needed to measure voltage.
  • Keep the piezo/storage circuit separate from ESP32 pins unless a designed, protected measurement interface is used.
ARDUINO IDE · ESP32-WROVER-IE

Arduino Code

Firmware for the VibeVolt dashboard API. The code reports temperature as unavailable and does not enable piezo input until its safe signal circuit is confirmed.

Before uploading: Set your Wi-Fi credentials and verify the GPIO map, ACS712 version, voltage-sensor circuit and calibration. This code cannot guarantee calibrated readings until those hardware details are confirmed.
rail_urja_esp32.ino
#include <WiFi.h>
#include <WebServer.h>

// RAIL-URJA / VibeVolt firmware for ESP32-WROVER-IE
// GPIO choices are provisional. Verify the actual wiring.

const char* WIFI_SSID = "YOUR_WIFI_NAME";
const char* WIFI_PASSWORD = "YOUR_WIFI_PASSWORD";

constexpr int PIN_ACS712 = 34;
constexpr int PIN_VOLTAGE = 35;
constexpr int PIN_IR = 27;
constexpr int PIN_PIEZO_CONDITIONED = 32;

// Select the correct sensitivity for your ACS712 version:
// 5A: approx 0.185 V/A; 20A: approx 0.100 V/A;
// 30A: approx 0.066 V/A.
constexpr float ACS_SENSITIVITY = 0.100f;

// Example only. Calibrate for your actual voltage circuit.
constexpr float VOLTAGE_RATIO = 5.0f;

// Verify whether your IR output goes LOW or HIGH on detection.
constexpr bool IR_ACTIVE_LOW = true;

// Keep false until a protected, conditioned piezo signal
// circuit has been installed and verified.
constexpr bool PIEZO_CIRCUIT_CONFIRMED = false;

WebServer server(80);

float voltageV = 0;
float currentA = 0;
float powerW = 0;
float energyWh = 0;
bool obstacle = false;
bool vibration = false;
unsigned long lastSampleMs = 0;

float adcVolts(int pin) {
  return analogRead(pin) * (3.3f / 4095.0f);
}

float readCurrentAmps() {
  float total = 0;
  const int samples = 100;

  for (int i = 0; i < samples; i++) {
    total += adcVolts(PIN_ACS712);
    delayMicroseconds(200);
  }

  float averageV = total / samples;

  // Must be measured with zero current flowing.
  // 2.5 V is only an assumption, not calibration.
  const float zeroCurrentV = 2.5f;

  return (averageV - zeroCurrentV) / ACS_SENSITIVITY;
}

void sampleSensors() {
  unsigned long now = millis();

  if (lastSampleMs == 0) {
    lastSampleMs = now;
    return;
  }

  unsigned long elapsed = now - lastSampleMs;
  if (elapsed < 250) return;
  lastSampleMs = now;

  // Requires a suitable voltage measurement circuit on GPIO 35.
  voltageV = adcVolts(PIN_VOLTAGE) * VOLTAGE_RATIO;
  currentA = readCurrentAmps();

  // Approximation for a suitable DC output measurement.
  powerW = voltageV * currentA;

  obstacle = (digitalRead(PIN_IR) ==
              (IR_ACTIVE_LOW ? LOW : HIGH));

  // Never connect a raw piezo disc directly to GPIO.
  if (PIEZO_CIRCUIT_CONFIRMED) {
    vibration = analogRead(PIN_PIEZO_CONDITIONED) > 500;
  } else {
    vibration = false;
  }

  // Approximate energy integration in watt-hours.
  // Accuracy depends on proper voltage/current measurement.
  energyWh += powerW * (elapsed / 3600000.0f);
}

void sendReadings() {
  sampleSensors();

  String json = "{";
  json += "\\"voltage\\":" + String(voltageV, 3) + ",";
  json += "\\"current\\":" + String(currentA, 3) + ",";
  json += "\\"power\\":" + String(powerW, 3) + ",";
  json += "\\"temperature\\":null,";
  json += "\\"energy\\":" + String(energyWh, 6) + ",";
  json += "\\"vibration\\":";
  json += vibration ? "true" : "false";
  json += ",";
  json += "\\"obstacle\\":";
  json += obstacle ? "true" : "false";
  json += "}";

  server.sendHeader("Access-Control-Allow-Origin", "*");
  server.sendHeader("Cache-Control", "no-store");
  server.send(200, "application/json", json);
}

void handleOptions() {
  server.sendHeader("Access-Control-Allow-Origin", "*");
  server.sendHeader("Access-Control-Allow-Methods", "GET, OPTIONS");
  server.sendHeader("Access-Control-Allow-Headers", "Content-Type");
  server.send(204);
}

void setup() {
  Serial.begin(115200);
  analogReadResolution(12);
  pinMode(PIN_IR, INPUT);

  WiFi.mode(WIFI_STA);
  WiFi.begin(WIFI_SSID, WIFI_PASSWORD);

  Serial.print("Connecting to Wi-Fi");
  unsigned long start = millis();

  while (WiFi.status() != WL_CONNECTED &&
         millis() - start < 20000) {
    delay(500);
    Serial.print(".");
  }

  Serial.println();

  if (WiFi.status() == WL_CONNECTED) {
    Serial.println("Wi-Fi connected");
    Serial.print("ESP32 IP: ");
    Serial.println(WiFi.localIP());
  } else {
    Serial.println("Wi-Fi connection failed.");
    Serial.println("Check credentials and restart.");
  }

  server.on("/", HTTP_GET, []() {
    server.send(200, "text/plain",
      "RAIL-URJA VibeVolt is online. Use /api/readings");
  });

  server.on("/api/readings", HTTP_GET, sendReadings);
  server.on("/api/readings", HTTP_OPTIONS, handleOptions);
  server.begin();

  Serial.println("HTTP server started");
}

void loop() {
  server.handleClient();
}
Dashboard endpoint: /api/readings. JSON fields match the VibeVolt dashboard. Temperature remains null until the sensor is identified.
NETWORK SETUP

Connect ESP32 to Wi-Fi

Step 1 · Configure Arduino

In the Arduino Code section, replace these two values with your router's credentials:

const char* WIFI_SSID = "YOUR_WIFI_NAME";
const char* WIFI_PASSWORD = "YOUR_WIFI_PASSWORD";

Keep your password private. Do not put it in the public website code.

Step 2 · Upload firmware

  1. Install Arduino IDE and the ESP32 board package by Espressif Systems.
  2. Select the correct ESP32 board and port.
  3. Upload the sketch.
  4. Open Serial Monitor at 115200 baud.
  5. Read the printed ESP32 IP address.

Step 3 · Link the dashboard

Your laptop and ESP32 should be connected to the same router network. Enter the ESP32 IP address below.
